## 实现与调整

采用 NetworkX 图模型；自编算法与独立库或数学恒等式核对。社区模型采用无权目标和固定种子，客户关系明细不公开。

修复源脚本不可达目标和起终点相同的路径重建；DFS 保持邻接表访问顺序。BFS 求无权最短路，DFS 仅保证可达路径。
