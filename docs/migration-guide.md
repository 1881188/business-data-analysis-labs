# 首批实验的迁移说明

## B05：先确定粒度，再转换公式

原Excel参考的F是不同流水号数。65,989行商品明细只有26,735笔消费，不能把行数直接当消费次数，也不能按消费日去重。R使用2019-08-03减最后消费日；R低于均值才标高，F和M高于均值才标高，相等归低。

原始明细保持全部行，金额转换成整数分后求和。Python结果与参考答案逐个客户比较集合、日期、F、M、R和分层，差异文件为空才标“参考核对通过”。参考工作簿已有缓存值只作外部对照，没有修改或重算Excel文件。

## S01：交互展示变为可保存过程

源Notebook有12个Markdown教学小节、94个代码单元（含空单元）。整理后的脚本覆盖全部小节，将重复展示合并成45个可检查的演示产物；不声称新脚本逐句保留每个交互表达式。

分块CSV与完整读取逐项比较；横向连接验证键唯一性；索引连接和字段连接分开演示；透视表指定求和并核对守恒。原Notebook写`write.csv`的行为改为写实验输出，避免覆盖教材文件。

## S11：运行成功也要检查统计含义

原代码存在两项重要评价问题：阈值循环的指标名称与分母错配；在测试集上选取阈值。整理版以churn=1为正类，用标准混淆矩阵公式评价，并从原训练分区内部划出验证集选阈值。外层测试仍沿用原random_state=666抽样。

教材固定多元公式的未正则估计在实测环境中没有收敛，不能给它贴“复现成功”。保留公式、失败状态和极端系数诊断，实际主模型采用相同预测变量，经训练内标准化、独热编码和L2正则化后拟合。C固定为1.0，没有在测试集调参。分类检验和前向AIC保留为训练集内的独立教学诊断。

参考：[scikit-learn关于预处理与数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)、[LogisticRegression 1.6文档](https://scikit-learn.org/1.6/modules/generated/sklearn.linear_model.LogisticRegression.html)。
