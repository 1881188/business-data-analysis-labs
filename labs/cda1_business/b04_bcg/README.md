实现：[bcg.py](../../../src/bda_labs/bcg.py)。[结果报告](../../../docs/results/B04/report.md)。

业务问题：在现金周转较紧时，识别本公司E-J品牌的销售位置。教材横轴是两个月合计销售额占比，纵轴是八月对七月的环比。阈值使用全市场14个品牌的平均份额和全市场增长率，没有改成相对最大竞争者份额。金额按单价乘销量以整数分计算。

14个品牌的份额、增长率及两条阈值已核对。没有可读取的逐品牌参考标签，象限标签按明确的阈值规则计算；不能把这部分也当成标签对账。等于阈值归高，前期销售为0时增长不可比较。缺少利润和长期市场信息，不直接作退出决策。
