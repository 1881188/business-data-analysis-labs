# B01 关系与维度模型

问题：识别主外键、权限桥和事实粒度，让多表汇总不重复计量。

在仓库根目录运行：

```powershell
python run_labs.py --lab B01
```

[独立入口](main.py)调用[data_models.py](../../../src/bda_labs/data_models.py)。prepare_mall统一案例商品编码大小写，保留事实单价，并以本行数量×单价重算销售额。check_mall_formulas仅解析明确乘法引用，区分缓存正确与业务错行。bank_models先分别聚合各子事实，再关联账户，以SQLite独立核对持卡和贷款所有者分析。

银行1056320笔交易分块读取。商场12960个缓存均符合原式，但4个式子错引下一行，正式合计410068720，缓存410116740，相差48020。2075行事实价与维表价不同，未擅自替换。PowerBI自动影响因素算法及界面未逐项复刻。

结果、教材差异与边界见[实验报告](../../../docs/results/B01/report.md)。原始工作簿、CSV和PBIX只读；客户、学生、手机号及订单级数据仅留本地outputs。公开内容按允许列表发布。
