# B07 同期群日留存

来源：一级教材第2章同期群用户登录资料与参考答案。

```powershell
python run_labs.py --lab B07 --data-root "教材资料目录"
```

实现：[cohort.py](../../../src/bda_labs/cohort.py)。[结果报告](../../../docs/results/B07/report.md)。

活动日期2020-07-01至07-09，观察截止07-31。按注册日期分组、同用户同日登录去重，D0为首日、D1为次日。已到观察日而未登录计0，尚未到期保留空白。

核对18项活动期每日人数、243个已观察群体日比率及31项教材总计。教材总计每个日龄都用全部1001人为分母；迁移版额外提供按已达到该日龄的群体计算的汇总。D30实际只有131人达到观察日，两种分母需明确区分。

完整31日聚合矩阵可公开，没有用户级记录。资料缺少独立注册总表，不能证明包含从未登录的注册用户；曲线变化不直接证明促销或竞品活动的影响。
