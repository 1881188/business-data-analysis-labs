# Olist电商销售与履约分析

《商业数据分析》个人期末项目。研究2017年1月至2018年7月Olist已交付订单的销售增长、品类贡献与配送体验，并以手表与礼品的下单金额做短期预测。代码与成果独立放在`final_project/olist/`，不影响课程仓库其他实验。

2018年1—7月商品金额比2017年同期增长161.59%，主要伴随订单数增加；17个A类品类贡献全部商品金额的79.85%。配送逾期与低评分有关，不能据此解释因果。SARIMA相对较强的4周同星期均值基线，仅降低1.67%的测试RMSE，预测能力有限。

## 数据与口径

数据来自[Olist的Kaggle官方数据集](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)，2026-10-19通过官方下载端点获取，无网页抓取；许可CC BY-NC-SA 4.0，详见[数据说明](data/README.md)、[来源校验清单](data/raw/source_manifest.json)与[使用范围](DATA_LICENSE.md)。原始99,441笔订单、112,650条商品明细，分析窗口内89,860笔合格已交付订单。无抽样、无合成交易。ZIP、原始与清洗明细仅在本地生成，不上传GitHub。

销售金额=sum(price)，以整数分计算，BRL为巴西雷亚尔，不含运费、不代表利润。支付与商品分表先聚合再关联。缺失品类保留U类，ABC阈值80%/95%，另检查75%/90%与85%/97%。逾期与评价分析保留有效分母并按州×主要品类分层核对。预测使用各最终状态的下单商品金额，与已交付销售口径不同。

## 复现

实测Python 3.12，依赖版本见`requirements.txt`。从仓库根目录进入本项目后运行：

```powershell
cd final_project/olist
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_all.py
.\.venv\Scripts\python.exe run_dashboard.py
```

看板访问http://127.0.0.1:8050/，Ctrl+C停止；端口占用可加`--port 8051`。一键入口执行12个脚本：下载、初检、清洗、分析、预测、样图、独立结果核对、15张原图、图表文件核查、看板HTTP回调核查、8组论文图重绘、10种模板总览拼排。它不启动长期服务，也不重新排版论文。

首次下载需要联网；若官方下载要求登录，在官方页下载ZIP并命名为`data/raw/brazilian-ecommerce.zip`后重跑。原ZIP存在时检查CRC与CSV内容，不覆盖有改动的原始文件。首次副本校验记录与仓库保存的清单比较，可确认数据版本。完整一键流程会更新本地可再生结果及阶段说明。已有清洗表时`python run_all.py --from-stage 4`重跑分析，`--from-stage 8`重绘图；论文组合图可单独运行`python scripts/11_paper_panels.py`。

Windows默认使用微软雅黑；其他系统需安装中文字体，并将`OLIST_CHINESE_FONT`设为字体文件路径。requirements安装需要网络；本项目依赖独立于仓库其他实验。

## 模型与图表

三种核心方法为同比环比、品类ABC和SARIMA，分别产出2张核心图及业务结论；配送与评分为补充分析。预测按时间划分：训练截至2018-05-31，6月验证选型，7月独立测试；选用SARIMA(0,1,1)×(0,1,1,7)，测试RMSE=1367.55 BRL、WAPE=32.55%，提供95%预测区间，2018年8月为历史模拟，不能直接作为补货数量。

共15张Python原图，覆盖参考模板01、02、03、06、08、11、13、19、20、26共10种类型；原图1920×1080、160dpi。论文按主题组合成8组240dpi图，各视图均在正文解读。第5章按探索性分析、模板复现、业务模型图和交互大屏四节组织；5.2新增标明模板编号与原图编号的10图总览，5.3列清三种方法对应的6张核心图。模板映射及各图正文位置见[章节对应](docs/08_模板复现与章节对应.md)。图表与模型、数据表及范围对应见[图表索引](docs/05_图表索引与解读.md)。

## 交互看板与验证范围

日期、收货州、品类联合筛选，联动4个KPI、4张图和订单明细，支持CSV导出与重置。品类筛选仅汇总所选商品，订单去重；配送与评分仍属整单结果，明细分列所选金额及整单金额。

金额守恒、关联基数、预测误差独立复算、筛选回调、空结果、CSV和重置均有脚本核查。页面实际操作与视觉验收截至2026-11-04仍待完成，尚无真实截图，详情及复核步骤见[截图目录说明](outputs/screenshots/README.md)。HTTP检查通过不等同于页面已验收。
