# 数据准备

教材原始配套资料保持只读，不直接复制进公开仓库。请从课程提供的资料中准备下列四个目录，并将它们的父目录作为`--data-root`：

```text
course-materials/
├── 1《CDA 一级认证教材：商业数据分析》/
├── 2《CDA 二级认证教材：量化策略分析》/
├── 3《CDA 三级认证教材：敏捷数据挖掘》/
└── 4《金融数据分析和数据挖掘案例实战》/
```

当前79个编号入口使用[输入清单](../config/datasets.json)中的230个登记键，对应217条不同文件路径；扩展名计数为：.csv 71份、.docx 1份、.ipynb 55份、.lp 3份、.pbix 11份、.png 2份、.pptx 5份、.sql 4份、.xes 1份、.xlsx 64份。多个入口可使用同一原文件，不重复计为新材料。清单给出准确相对路径、字节数和SHA-256。Notebook仅作教学意图、覆盖与参考读取，不执行原单元格。

三级/金融的逐源方法和限制见[迁移说明](../docs/advanced-migration.md)。F01所需data12261.csv缺失，未伪造或用其他数据代替。Vintage使用随材料提供的SQL备份离线解析；个人关系、信用特征和评分均不公开。

以下三种指定方式按优先级使用：

1. 命令行`--data-root`。
2. 环境变量`BDA_DATA_ROOT`。
3. `config/datasets.local.json`中的`data_root`，格式见[示例](../config/datasets.example.json)。

都未提供时，会检查本仓库同级的`a商业数据分析平时作业`目录。没有资料时明确报错，不在线搜索替代、不生成伪造教材数据。资料版本哈希变化时停止，需先确认列结构和参考结果。

## 本地和公开输出

`outputs/`含客户明细、预测和中间过程，不纳入Git。`tools/build_docs.py`只复制明确列出的聚合报告与图表到`docs/results/`。用于CI的测试数据由测试代码现场生成，不冒充教材数据。

更换源文件、时间窗口或计算口径后，需要重跑并重建文档，不能把旧结果当成当前代码的新结果。原始教材、报告、视频、插件和模型文件的公开授权尚未统一确认，本仓库不提供其下载镜像。

B13发布范围单独收紧：`local_*.png`、`private_summary.json`、参考截图核对值、真实汇总表及明细都只留本地。公开B13产物仅限报告、运行来源摘要、工作表去向与`synthetic_`示例；后者不含教材真实值。

B14/B15的`employees_private.csv`、`students_private.csv`、`ranking_private.csv`只保存在本地；公开允许列表不含姓名、工号、学号、生日或逐人成绩。筛选运行请用单独输出目录，构建工具拒绝筛选结果覆盖默认公开报告。

B18/B19的`audience_private.csv`、`age_formula_checks_private.csv`、`purchases_private.csv`、`decomposition_private.csv`不公开。B19筛选运行另用输出目录，构建工具拒绝其覆盖默认全量报告。WordCloud插件不执行、不捆绑。

B20的`applications_private.csv`、B21的`card_features_private.csv`仅留本地；公开结果不含申请/卡/客户/账户标识与逐卡历史日期特征。B22只发布已提供的聚合时间序列和新模型输出，保留原尺度、未知预测算法与近似区间说明。
