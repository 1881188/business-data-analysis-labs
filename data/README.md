# 数据准备

教材原始配套资料保持只读，不直接复制进公开仓库。请从课程提供的资料中准备下列四个目录，并将它们的父目录作为`--data-root`：

```text
course-materials/
├── 1《CDA 一级认证教材：商业数据分析》/
├── 2《CDA 二级认证教材：量化策略分析》/
├── 3《CDA 三级认证教材：敏捷数据挖掘》/
└── 4《金融数据分析和数据挖掘案例实战》/
```

首批只需要[输入清单](../config/datasets.json)中的5个文件：RFM原始/参考工作簿、数据清洗sample.csv及big.csv、电信客户流失CSV。清单给出准确相对路径、文件字节数和SHA-256。原始与参考文件必须分别保留，不能互相覆盖。

以下三种指定方式按优先级使用：

1. 命令行`--data-root`。
2. 环境变量`BDA_DATA_ROOT`。
3. `config/datasets.local.json`中的`data_root`，格式见[示例](../config/datasets.example.json)。

都未提供时，会检查本仓库同级的`a商业数据分析平时作业`目录。没有资料时明确报错，不在线搜索替代、不生成伪造教材数据。资料版本哈希变化时停止，需先确认列结构和参考结果。

## 首批字段

| 实验 | 粒度与关键字段 | 处理 |
|---|---|---|
| B05 | 一行商品销售明细；流水号、用户编号、销售日期、销售金额 | F按不同流水号计数，M按所有明细金额求和，金额用整数分 |
| S01 | sample.csv：id/name/scores；big.csv：ID/CNT_TBM/CNT_ATM/CNT_POS | 文件只读；其余小表和随机数是明确标注的教学演示 |
| S11 | 每行一个不同subscriberID；churn是0/1标签，AGE使用CSV实际大写字段名 | ID不入模；检查缺失、标签和分区重叠；数值变量只在对应训练分区标准化 |

## 本地和公开输出

`outputs/`含客户明细、预测和中间过程，不纳入Git。`tools/build_docs.py`只复制明确列出的聚合报告与图表到`docs/results/`。用于CI的测试数据由测试代码现场生成，不冒充教材数据。

更换源文件、时间窗口或计算口径后，需要重跑并重建文档，不能把旧结果当成当前代码的新结果。原始教材、报告、视频、插件和模型文件的公开授权尚未统一确认，本仓库不提供其下载镜像。
