# 数据准备

教材原始配套资料保持只读，不直接复制进公开仓库。请从课程提供的资料中准备下列四个目录，并将它们的父目录作为`--data-root`：

```text
course-materials/
├── 1《CDA 一级认证教材：商业数据分析》/
├── 2《CDA 二级认证教材：量化策略分析》/
├── 3《CDA 三级认证教材：敏捷数据挖掘》/
└── 4《金融数据分析和数据挖掘案例实战》/
```

当前22个实验使用[输入清单](../config/datasets.json)中的63个文件：26份Excel、21份CSV、11份Notebook、3份PPTX与2份PBIX。清单给出准确相对路径、文件字节数和SHA-256。Notebook用于读取教学说明、单元格范围和已保存的参考输出，不执行原单元格。原始与参考文件必须分别保留，不能互相覆盖。

以下三种指定方式按优先级使用：

1. 命令行`--data-root`。
2. 环境变量`BDA_DATA_ROOT`。
3. `config/datasets.local.json`中的`data_root`，格式见[示例](../config/datasets.example.json)。

都未提供时，会检查本仓库同级的`a商业数据分析平时作业`目录。没有资料时明确报错，不在线搜索替代、不生成伪造教材数据。资料版本哈希变化时停止，需先确认列结构和参考结果。

## 字段与业务粒度

| 实验 | 粒度与关键字段 | 处理 |
|---|---|---|
| B01 | 银行8表、商场6表、销售模型4表；PBIX/课件为配置和定义来源 | 权限桥与唯一键核查，事实表先聚合；商场4处错行式单独记录，事实价不被维表价覆盖 |
| B02 | 5工作簿31张表，292个保存公式；源时钟2025-02-02 | 缓存只作指定范围核对，2个随机格不逐值比较；查找错误键隔离，透视读取实际济南筛选 |
| B03 | 5工作簿11张表；27条订单明细、2条拆列示例 | 保留真实零与错误坐标，拆分不编造数量分配，季度异名字段显式映射 |
| B04 | 每行一笔订单；订单ID、日期、品牌、规格、单价、销量 | 单价×销量以整数分汇总，份额以两个月合计金额为基准 |
| B05 | 一行商品销售明细；流水号、用户编号、销售日期、销售金额 | F按不同流水号计数，M按所有明细金额求和，金额用整数分 |
| B06 | 每行商品明细；订单编号、会员编号、消费日期、消费金额 | 先分潜在/易流失，再对其余会员的年度F/M评分 |
| B07 | 每行登录记录；用户编号、注册日期、登录时点 | 同用户同日去重，日龄未到期保持缺失 |
| B08 | 汇总阶段人数，非逐用户事件路径 | 区分逐级与累计比率，分母为0时不可用 |
| B09 | 58对x/y数值，未提供业务单位 | 相关与样本内拟合；参考只提供舍入后的图表系数 |
| S01 | sample.csv：id/name/scores；big.csv：ID/CNT_TBM/CNT_ATM/CNT_POS | 文件只读；其余小表和随机数是明确标注的教学演示 |
| S02 | 2017年15个交易日的OHLC；其余为模拟/示意数据 | 日期排序，保留原数值，13幅图，无界面运行 |
| S03 | 16,210条房源记录；AREA/price | ddof=1样本方差，线性插值分位数，明确单位缺失 |
| S04 | 5,369名客户、77个Dist地区 | 不放回，比例向上取整，系统抽样随机起点，分层权重N_h/n_h |
| S05 | 9,686名营销客户；AvgIncome/AvgHomeValue等 | 仅按案例规则替换收入0，其他字段保留，明细只留本地 |
| S06 | 600名电信客户；4项使用计数 | ID不入模，ddof=0标准化，PCA得分按样本特征值白化 |
| S07 | 10个地区、X1-X9经济指标 | GBK编码，主成分单位特征向量做varimax；不改成共同因子模型 |
| S08 | 100名客户，30条消费额空白且均为Acc=0 | 主分析70条观察消费额；教材空白填0分支单独核对，不可识别交互不强行估计 |
| S09 | 5,845条申请，bankruptcy_ind缺失217条 | 完整样本5,628条，展示表可含合计，卡方仅用2×2真实频数；原weight定义不明，未加权 |
| S10 | 76条信用卡记录，消费额缺失6条；999年龄与教育缺失同属一条响应缺失记录 | 正式70条，目标不填补；5个教材兼容模型仅复核，验证预处理在训练内 |
| S11 | 每行一个不同subscriberID；churn是0/1标签，AGE使用CSV实际大写字段名 | ID不入模；检查缺失、标签和分区重叠；数值变量只在对应训练分区标准化 |
| S12 | 100,000名客户，四渠道整数计数，CNT_TOT为四项之和 | ID和派生总数均不入模；描述性分群、替代树，不当作业务真值预测 |
| S13 | 第9章10地区表与提供的fa_cities_10.csv | AREA按本章，重算结果写outputs；2维得分保持原尺度作Ward聚类 |

## 本地和公开输出

`outputs/`含客户明细、预测和中间过程，不纳入Git。`tools/build_docs.py`只复制明确列出的聚合报告与图表到`docs/results/`。用于CI的测试数据由测试代码现场生成，不冒充教材数据。

更换源文件、时间窗口或计算口径后，需要重跑并重建文档，不能把旧结果当成当前代码的新结果。原始教材、报告、视频、插件和模型文件的公开授权尚未统一确认，本仓库不提供其下载镜像。
